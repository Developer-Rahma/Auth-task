# Frontend package

The project documentation for the full frontend, including setup, routes,
architecture, styling, API integration, authentication, and tests, is in the
[frontend guide](../README.md).

This directory (`web/`) contains the Vite React application.

## Quick start

```powershell
npm install
npm run dev
```

Run `npm run build`, `npm run lint`, and `npm test` for the frontend checks.
